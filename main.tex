\begin{abstract}
We introduce a distributed inference framework for recovering latent truth under adversarial noise. We model truth as a hidden variable in a probabilistic generative model and propose a contractive operator combining Bayesian multiplicative updates with gossip-based consensus. We prove exponential convergence to the Bayesian posterior under bounded likelihood assumptions and establish robustness guarantees under Byzantine corruption. Empirical results demonstrate stability across network topologies and adversarial ratios.
\end{abstract}

\section{Introduction}

Distributed truth inference is a fundamental problem in multi-agent systems, decentralized learning, and information aggregation under uncertainty. Existing approaches such as majority voting and classical consensus fail under adversarial conditions or lack probabilistic grounding.

We propose a unified framework combining Bayesian inference and gossip dynamics.

\section{Problem Setup}

Let $\mathcal{H} = \{h_1, ..., h_k\}$ be a finite hypothesis space. Let $h^* \in \mathcal{H}$ denote the latent truth:

\[
h^* \sim \pi(h)
\]

Each agent observes:

\[
o_v \sim P(o \mid h^*)
\]

and maintains belief:

\[
p_v(t) \in \Delta^{k-1}
\]

\section{Generative Model}

Observations are conditionally independent:

\[
o_v \perp o_u \mid h^*
\]

Byzantine agents produce arbitrary observations:

\[
o_v \sim Q_v(o)
\]

\section{Algorithm}

\subsection{Local Update}

\[
\hat{p}_v(h) =
\frac{p_v(h) P(o_v \mid h)}
{\sum_{h'} p_v(h') P(o_v \mid h')}
\]

\subsection{Gossip Step}

\[
p_v(t+1) = \sum_u W_{vu} \hat{p}_u(t)
\]

\section{Theoretical Results}

\subsection{Local Contraction}

\[
D_{KL}(\hat{p}_v \| p^*) \leq D_{KL}(p_v \| p^*) - \eta \|p_v - \hat{p}_v\|_1^2
\]

\subsection{Global Contractivity}

Let:

\[
\Phi(t) = \sum_v D_{KL}(p_v(t) \| p^*)
\]

Then:

\[
\Phi(t+1) \leq (1 - \gamma \eta)\Phi(t)
\]

\subsection{Byzantine Robustness}

If $\beta$ fraction is adversarial:

\[
\Phi(t+1) \leq (1 - \gamma \eta)\Phi(t) + C\beta
\]

\end{itemize}

We present a contractive distributed inference framework with provable convergence and Byzantine robustness.
